# Nischay Consultancy

A premium, modern corporate website built for an architectural and structural engineering consultancy. The project showcases a sophisticated, highly responsive digital presence with a focus on elegant typography, smooth animations, and high-end UI/UX principles.

## 🚀 Live Demo

*(https://www.nischayconsultancy.com/)*

## ✨ Key Features

- **Kinetic Wireframe Hero**: A custom, mesmerizing 3D-like geometric animation built with Framer Motion, representing architectural structure and space without relying on generic stock photos.
- **Glassmorphism UI**: Beautiful, frosted-glass components (`backdrop-blur`) that provide a premium, modern aesthetic.
- **Fluid Responsiveness**: Typography and layouts utilizing CSS `clamp()` and Tailwind breakpoints to ensure flawless presentation across all devices (mobile to ultra-wide desktop).
- **Advanced Micro-Interactions**: Hover effects that trigger subtle structural changes, dynamic drop-shadows, and elegant clip-path wipe reveals.
- **Performance Optimized**: Built on Next.js App Router for optimal rendering performance, utilizing `next/image` for image optimization and optimized font loading.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 📂 Project Highlights

### Architectural Design Language
The design system leans heavily into an "architectural intelligence" vibe. It uses a refined monochromatic color palette, widely tracked serif typography for headings, and extremely clean 1px borders and grid lines to evoke blueprints and structural drafting.

### The Hero Section (`Hero.tsx`)
The centerpiece of the site is the interactive hero section. It features three massive, intersecting wireframe rings rotating continuously on different axes to simulate a 3D kinetic sculpture. Overlaid on this is an interactive glassmorphism nameplate that scales and reveals deeper depth-of-field on hover.
